ESP32 配网 & OTA 控制台

蓝牙配网 → WiFi → HiveMQ → 空中升级 · 需 Chrome / Edge (桌面或安卓), 页面须 https / localhost
1蓝牙连接
点"连接 ESP32", 在弹窗里选择名为 ESP32-OTA 的设备
2WiFi 配网
3让 ESP32 记住 HiveMQ
配置会写入 ESP32 的 NVS, 下次开机自动连, 无需重配。
4网页连 HiveMQ (可选)
用于收发测试消息, 以及"远程 URL 升级"(往 前缀/ota 发布固件URL)。用上面第 3 步的地址/用户名/密码。
5空中升级 OTA
选编译出的 *.ino.bin(应用镜像, 不是 merged/factory)。约 1~3 分钟, 完成后自动重启。
HTTPS 直链即可(GitHub Release 直链可用)。MQTT 方式需先完成第 4 步。
